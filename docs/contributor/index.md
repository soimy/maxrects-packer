# Contributing

Everything a contributor needs, in the order it usually comes up.

- [Development](./development.md) — clone, install, the scripts, worktrees, project layout.
- [Testing](./testing.md) — the vitest suite, coverage, what a new test has to look like.
- [Architecture](./architecture.md) — module responsibilities and the packing data flow.
- [Behaviour contracts](./behavior-contracts.md) — the promises the library makes; breaking one is a
  breaking change.
- [Compatibility](./compatibility.md) — ES5 output, the TypeScript 6/7 setup, entry points and what the
  published tarball contains.
- [Documentation](./documentation.md) — how this site is built, and the boundary between tracked source
  and generated output.
- [Releasing](./releasing.md) — commit conventions, PR titles, changelog and release steps.

[`CONTRIBUTING.md`](https://github.com/soimy/maxrects-packer/blob/master/CONTRIBUTING.md) is the entry
point for a first-time contributor: language policy, ways to contribute, the commit format and the PR
checklist. [`AGENTS.md`](https://github.com/soimy/maxrects-packer/blob/master/AGENTS.md) is the shorter,
mandatory version of the same rules aimed at AI agents.

**All repository communication is in English** — commits, PRs, issues, code comments and these pages.
