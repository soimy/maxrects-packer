# Releases

The release history is [`CHANGELOG.md`](https://github.com/soimy/maxrects-packer/blob/master/CHANGELOG.md),
generated from the commit messages on `master` by
[`commit-and-tag-version`](https://github.com/conventional-changelog/commit-and-tag-version) — which is
also why a commit type decides whether a change is user-visible at all. The currently published version
is on [npm](https://www.npmjs.com/package/maxrects-packer).

How a release is cut — the commit and PR title rules, breaking-change markers, the tag workflow and the
manual `npm publish` step — is documented in
[Releasing](../contributor/releasing.md).

This site is built from the `master` branch. Its content therefore tracks the source, which may be a
little ahead of the version published to npm; the API reference is generated from that same revision.
For behaviour that only exists in a release, check the changelog entry for the version you installed.
